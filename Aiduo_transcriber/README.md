# AudioTranscriber

**AudioTranscriber** — учебное приложение на Python для автоматического распознавания речи из аудиофайлов с использованием нейронной сети OpenAI Whisper.

Программа имеет графический интерфейс и позволяет преобразовывать аудиозаписи в текст.

## Возможности

- Загрузка аудиофайлов.
- Распознавание речи на русском и английском языках.
- Автоматическое определение языка.
- Выбор модели Whisper (`tiny`, `base`, `small`).
- Отображение результата распознавания.
- Сохранение текста в форматах TXT и SRT.
- Сохранение истории распознаваний.
- Настройка внешнего вида приложения.

## Используемые технологии

| Технология | Назначение |
|---|---|
| Python | Основной язык программирования |
| OpenAI Whisper | Распознавание речи |
| CustomTkinter | Графический интерфейс |
| FFmpeg | Обработка аудиофайлов |
| JSON | Хранение истории распознаваний |

## Использование

1. Запустите приложение.
2. Выберите аудиофайл.
3. Укажите язык распознавания или выберите автоматическое определение.
4. Выберите модель Whisper.
5. Нажмите кнопку распознавания.
6. Дождитесь завершения обработки.
7. Просмотрите или сохраните полученный текст.

## Особенности

Распознавание выполняется на CPU. Скорость обработки зависит от мощности компьютера, продолжительности аудиозаписи и выбранной модели Whisper.

При первом использовании выбранная модель может загружаться автоматически.
